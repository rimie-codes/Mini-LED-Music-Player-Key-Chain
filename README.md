# 🔑🌈 LED Music Keychain

A cute Bluetooth keychain that lets you control music on your phone or laptop.

## 🎵 Features

- ⏮ Previous track
- ▶️ Play / Pause
- ⏭ Next track
- 🌈 Change LED colours
- 🔵 Bluetooth connection
- 🔑 Small keychain design

## 🧩 Components

- ESP32
- RGB LED
- 4 Push Buttons
- Battery
- Small keychain case

## ⚙️ How It Works

The ESP32 connects to a phone or laptop through Bluetooth
and sends media-control commands.

The phone/laptop plays the music, while the keychain controls it.

## 🎨 LED Modes

- Blue
- Purple
- Pink
- Red
- Green
- Yellow
- Cyan
- Rainbow
